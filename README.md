# IPL 2026 Ticket Booking Website

A simple IPL 2026 Ticket Booking website developed as part of my web development activities.

## Project Overview

This project provides a basic interface for exploring IPL matches, viewing ticket prices, and accessing a ticket booking form.

## Features

- Navigation bar with different sections
- IPL 2026 introduction
- Popular IPL teams and stadiums
- Match schedule with ticket prices
- Team filter dropdown
- Ticket booking form
- Booking summary section
- My Ticket Bookings section
- Ticket booking guidelines

## Technologies Used

- HTML5
- CSS3

## Activities

- **Activity 1:** HTML Structure for IPL Ticket Booking Website
- **Activity 2:** Styling the Web Page with CSS
